# Network, WiFi and VPN

## VPN will not connect
1. Check that your home internet works by opening any public website.
2. Quit the VPN client completely and start it again.
3. Update the VPN client to the latest version from the software portal.
4. Error 809 usually means a firewall or router blocks the VPN. Restart your router and try another network such as a phone hotspot.
5. If it still fails, send the client log file with your ticket.

## WiFi keeps disconnecting
1. Forget the network and reconnect with your work credentials.
2. Turn WiFi off and on, then restart the laptop.
3. Move closer to an access point, thick walls and microwaves cause drops.
4. Update the wireless adapter driver from the software portal.

## Slow internet or high latency
1. Run a speed test and note the result in your ticket.
2. Close cloud sync and streaming apps while testing.
3. Try a wired connection if a dock is available.
If many people on the same floor report slow speeds, it is likely an access point problem and the network team is notified automatically.

## Network drive not accessible
1. Confirm you are on the office network or connected to VPN.
2. Disconnect and re-map the drive from File Explorer.
3. Check that your account still has permission to the share.
