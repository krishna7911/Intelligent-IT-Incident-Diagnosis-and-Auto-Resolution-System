# Email and Outlook

## Outlook is not receiving emails
1. Check that Work Offline is switched off in the Send/Receive tab.
2. Look in Junk and Other folders for the missing messages.
3. Check your mailbox quota. A full mailbox stops new mail.
4. Restart Outlook, then create a new Outlook profile if the problem remains.

## Emails stuck in the Outbox
1. Open the stuck message and remove large attachments, the limit is 25 MB.
2. Send again, or press Send/Receive.
3. Restart Outlook if the message is still stuck.

## Mailbox full
1. Empty Deleted Items and Junk Email.
2. Archive items older than one year.
3. Request an archive mailbox through the helpdesk for more storage.

## Shared mailboxes and distribution lists
Raise a ticket with the name of the mailbox or list, the owner and the list of members that need access.
