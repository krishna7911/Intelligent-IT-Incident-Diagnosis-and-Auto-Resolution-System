# Software and Applications

## Application crashes or freezes
1. Save your work and fully close the application.
2. Restart the computer to clear memory.
3. Install pending updates for the application and for the operating system.
4. For Excel, open the file in Safe Mode by holding Ctrl while starting it, and disable add-ins.
5. For very large files, save a copy as binary workbook (.xlsb) to reduce size.

## Install new software
Approved software is available in the Company Software Portal.
1. Open the portal and search for the application.
2. Press Install and wait for the confirmation message.
3. If the app is not listed, raise a ticket with the business reason and your manager's name for approval.

## Microsoft Teams problems
1. Sign out of Teams and quit it from the system tray.
2. Clear the Teams cache folder, then start Teams again.
3. Check your camera and microphone permissions in system settings.

## Update failed with an error code
1. Restart the machine and run the update again.
2. Run the built-in update troubleshooter.
3. If error 0x80070005 appears, the helpdesk can fix file permissions remotely.
